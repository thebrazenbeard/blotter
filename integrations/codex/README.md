# Optional Codex lifecycle integration

The hook template supplies explicit acknowledged-history instructions at turn
and subagent start, and records sanitized host observations after supported
tools and turn stops. It does not substitute a latest-20 view for catch-up.

Replace the interpreter placeholders with reviewed absolute paths to an
ordinary installed package, then register and trust the exact hook definition
through the host. No host settings or credentials are changed by this directory.

See [configuration, behavior and qualification](../../docs/CODEX_INTEGRATION.md).
